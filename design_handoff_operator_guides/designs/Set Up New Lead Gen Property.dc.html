Set up a new lead gen property to collect leads

Wire a newly-ranked site so its leads flow into the dashboard, attributed correctly.

5 steps 2 hidden fields
{{ doneCount }} of {{ stepCount }} steps checked off

Why this matters

A new site is ranked and ready, but until it's wired up its leads go nowhere — or land in the dashboard unattributed. Getting the hidden fields right is what makes every lead route to the correct property automatically. The honeypot field is also what keeps bot spam out.

Two hidden fields do all the work
lead_source routes the lead
default value = the property's exact Lead Source from the routing table
website honeypot
default value = empty · anything arriving filled is flagged spam

Before you start

Have on hand:

Pre-flight
The property's exact name as shown in the dashboard routing table
Access to Engine Evolve
The property's website to embed the form on

Steps

1
Dashboard

Copy the Lead Source from the routing table

In the dashboard, open Settings → Webhooks → Routing table, find this property, and copy its exact Lead Source value with the copy button.

This is exactly what each Engine Evolve form must send in its Lead Source hidden field. Copy the value and paste it into the matching form. Calls route by the property's tracking number instead.

Add the lead_source hidden field

4
Honeypot

Add the website honeypot field

Add one more hidden field with the Query Key website, and leave its default value empty. This is the honeypot — a real person never fills it, so anything that arrives with it filled is auto-flagged as spam.

How to check it worked

In the dashboard, the property should now show a green connection dot next to its name. Submit a test lead through the form and confirm it appears on that property's page in Leads within a few seconds. If it lands in the unmatched queue instead, re-check the Lead Source value against the routing table.
